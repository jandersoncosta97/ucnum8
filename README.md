### How to install

Select a folder on your cmd. For example, in my case: cd C:\Users\jande\Documents\dev

and paste:

git clone https://github.com/jandersoncosta97/ucnum8.git

### Installation of packages

To install the packages, in your cmd, run:

conda env create -f requirements/environment.yml

### Activate the environment:

if you are using another environment, run:

conda deactivate Environment_NAME

And to activate our environment, run:

conda activate ucnum8

### Run the project

In the root of the project, run:

Python main.py

Chose the option you want to run.
